# Audited publication review
Design authority: founder response,26November2026. Isolated implementation only.
Reuse current sessions, current staff authority/MFA, shop ownership, product revision, review queue and separate seller publication.
A server-configured exact account UUID/shop UUID scope enables founder self-review only for the owner with current admin authority. No editable name/slug matching or role grants. Default absent scope denies self-review.
Queue returns a SHA256 hash of a canonical server snapshot. Approval/rejection requires exact hash/revision, an explicit decision, reason, unique request ID and explicit self-review acknowledgement when applicable. Save an append-only receipt with creator/reviewer, capacity, snapshot, category-policy version and timestamp in the same transaction. Edits invalidate approval; publication rechecks current policy and the matching receipt. Never label this independent third-party verification.
Restricted/unknown categories remain blocked; cosmetics require regulatory capability not implemented in this increment. Ordinary native pilot Fashion/Home remain manual-review categories, with fail-closed known restricted-content screening. This is not the complete universal taxonomy or a claim of comprehensive automated moderation. TAX-01–TAX-07 remains the next staged work.
An explicit review action for the scoped own shop can activate only the isolated shop after the same snapshot/reason/ack checks; product publication remains separate. No real scope, role or production resource will be activated.
Acceptance: ordinary seller denied; exact admin/owner scope plus acknowledgement succeeds; renamed/foreign shop cannot inherit scope; stale hash/revision, absent reason, revoked role, restricted goods and repeat request collisions denied; receipt retained across edits; one listing authority and disabled finance preserved.
Verification: write failing policy tests first, then real HTTP/auth/SQLite regressions; append proposed PostgreSQL schema, immutable privileges and exact-head remote checks. Full local browser output blocked by disk capacity; no physical/hosted claim.
