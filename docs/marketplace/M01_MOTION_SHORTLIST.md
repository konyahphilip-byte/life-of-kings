# Motion/component shortlist — 26 November 2026
Founder supplied ui.watermelon.sh, animejs.com, motion-primitives.com and kokonutui.com. These are references/candidates, not an instruction to install every overlapping runtime.

- Watermelon UI: [official requirements](https://ui.watermelon.sh/framework-support), [platform MIT licence](https://github.com/WatermelonCorp/watermelon-platform/blob/main/LICENSE). Evaluate individual source-backed fields, tabs and inventory patterns. Existing EcoVibes uses plain scoped CSS, not Tailwind; a registry install must not silently replace its design system.
- Motion Primitives: [installation](https://motion-primitives.com/docs/installation), [official CLI source/licence statement](https://github.com/ibelick/motion-primitives/blob/main/cli/README.md). Uses Motion + Tailwind + utility helpers. Direct homepage/carousel fetch returned403; exact component licence must be retained before source incorporation. Candidate for a small gallery/shared-layout experiment.
- Kokonut UI: [free component MIT licence](https://github.com/kokonut-labs/kokonutui/blob/main/LICENSE), [tool approval](https://kokonutui.com/docs/ai/ai-tool-approval), [diff review](https://kokonutui.com/docs/ai/ai-diff-review). Appropriate reference for Chale's permission/review UX; not proof of actual AI tools. Pro products are separate and not purchased or copied.
- Anime.js: [official docs](https://animejs.com/documentation/), [MIT licence](https://github.com/juliangarnier/anime/blob/master/LICENSE.md). Candidate for an original, lazy-loaded discovery interaction. Do not add it alongside Motion for the same animation.

Decision: native operating controls first. Preserve The Living Edit and all source. No UI-library packages or source copied yet. Pilot uses existing React/Lucide/scoped CSS and native dialog semantics. Next visual experiment should compare one small Motion pattern against one Anime.js interaction, measure transferred bytes, input responsiveness, reduced motion and low-end-device behavior; approve one coherent approach before integrating. No inference jobs, paid resources or production changes.

Image handling separately uses pinned Sharp0.35.5 (Apache-2.0; bundled libvips notices require retention), not a visual-effect dependency. Existing private storage adapter reused; bounded decode/reencode strips metadata. Official reference: https://sharp.pixelplumbing.com/api-output/.
