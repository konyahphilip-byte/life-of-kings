# Chale source-separated public updates

Founder approved BOTH EcoVibes activity/app updates and Ghana/world news with separate verified sources. This slice supplies versioned app release records and a bounded read-only news metadata reader. It does not invent activity counts or a popularity ranking. Home's static presentation figures are excluded. No private account query, user message, identity, location or conversation is sent to a news provider; separate fixed publisher-domain queries are used for Ghana and world coverage.

## Nine-file scope and source contracts

server/chale-updates.mjs and test; shared/chale-updates.mjs and types; server/index.mjs; Sidekick.tsx and test; scripts/test-chale-workflow.mjs; this receipt. Based on deployed main1a154cf5. No database/schema, secrets, permissions, existing model/provider/paid fallback, dependencies, billing or quota changes. Model-free updates remain behind the existing chat minute limit, or a six-per-minute read endpoint. App-only records require no news or inference request. Status scope is corrected to everyday_and_ecovibes, matching the founder-approved everyday feature. Client cards verify release-record equality, allowlisted publisher links, dates and text bounds; news does not enter the model prompt. External links suppress opener and referrer. App and Ghana/world groups remain separate.

News uses the original GDELT Project DOC API, not gdeltcloud.com. Primary sources inspected October26: [DOC API documentation](https://blog.gdeltproject.org/gdelt-doc-2-0-api-debuts/), [GDELT dataset terms](https://gdeltproject.org/about.html#terms-of-use) and [data access](https://gdeltproject.org/data.html). Dataset terms permit commercial use with attribution/link; the UI credits GDELT and links the originating publisher. Only title/URL/index date metadata is displayed, with no article body, image, scraper, paid API or account. Publisher allowlist: Ghana News Agency, MyJoyOnline, Graphic Online; Reuters, Associated Press, UN News. Domain selection is source verification, not independent fact-checking. GDELT seen time is labelled **Indexed**, never publication time. Each response reports its original check timestamp. Topic coverage/recency is not a popularity measurement.

Separate fixed Ghana/world queries guarantee independent geographic result budgets. Each has5s native fetch timeout, no redirects/cookies,256KiB/100 records, at most4 displayed headlines, HTTPS/host/port/credential/date/text checks, deduplication,15min single-flight cache and60s failure cooldown. Outbound operations are serialized with a bounded6s courtesy pause after completion; at most two group operations can be pending, so a cold combined lookup can take about16s. Separate status/timestamps expose partial failure. No retry/model/paid fallback. Invalid or older-than36h entries and dates beyond a five-minute future clock tolerance are omitted; failed refresh drops old news. Queries cannot supply a URL or arbitrary provider query. Model-free news does not consume the model allowance; existing rate limiting still applies. No background polling. App notes are maintained as reviewed source changes, not a promise of a complete automatically discovered release log.
