# Useful discovery across EcoVibes

October26 founder clarification: improve the recommendation algorithm within EcoVibes, so people discover worthwhile things and want to participate/create. This is not an onboarding replacement. The shared account-scoped opt-in topic profile already connects eligible Stories/Reels, follows, Marketplace, Quick&Handi and Chale catalog discovery. Other domains require real server-backed records and permission-safe signals first.

## This bounded Home selector

Version ecovibes-discovery-2026-10-26. Public/eligible catalog selection and authorization remain in the regular API. Current Home candidates are active in-stock direct products and open jobs, excluding the viewer's own records, bounded to250 recent records of each type. Existing item scoring retains declared-topic matches, decayed eligible interaction weights and freshness, with at most two items per category. No provider/model is needed.

For personalized lists with at least five available picks, keep the first four relevance-ranked picks and reserve at most the fifth slot for a different-topic record published within the last30days. It must not be future/invalid-dated, previously interacted with, positively matched to the current profile, dismissed, or tagged with a dismissed topic. Pick the freshest eligible candidate, breaking ties by typed item ID. Explain it as “Discover something different in [category]”. No candidate means ordinary ranking; small/cold-start/paused lists retain ordinary ranking. Limit is finite and clamped to0–24. Inputs are not mutated.

The algorithm reorders already eligible records; it never grants visibility or creates actions. Discovery searches the full eligible pool before category pruning and enforces the two-per-category limit against the final selection. Unsave/unlike stops active affinity but retained interaction rows still count as prior exposure; history uses the existing365-day/3,000-most-recent-topic-row bound, so novelty is bounded by retained history rather than lifetime knowledge. One discovery slot is a starting product rule, not a proven optimal ratio. There is no paid placement, popularity fabrication, cross-account profile access, new signal collection or inference cost. Explicit Chale catalog queries retain the existing relevance selector and do not receive unrelated exploration. Existing social/people ranking is preserved in this slice.

## User control and measurement

Keep existing chosen interests, opt-in learning, dismiss/save, explanations, pause and reset. Paused requests supply no profile to the selector. Reset clears learned activity while retaining chosen interests; it does not silently resume learning. Do not infer interests from private messages, identity documents, exact GPS, wallet/payment details or private Chale conversations.

Evaluate relevant saves, useful connections, successful applications/services, worthwhile creation and repeat unwanted recommendations, together with category/creator diversity and latency. Do not treat raw scroll time as the only success measure. Before broader tuning, evaluate separately with consenting real accounts and real eligible records; no claim of retention improvement or fairness is made from synthetic tests.
