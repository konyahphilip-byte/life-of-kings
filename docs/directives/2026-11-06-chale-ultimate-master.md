A user should be able to ask naturally:

- "Chale, what do you remember about me?"

- "What do you remember about my business?"
- "Why do you remember that?"
- "Forget this information."
- "Update what you remember."
- "Stop remembering this."
- "What did we discuss about my project?"

Chale must respond by retrieving the actual authorized memory records.

Never invent remembered details.

Never imply Chale remembers something that is unavailable in storage.

## 10.1 Memory overview

When the user asks what Chale remembers, present a clear and friendly summary.

Organize the display into categories such as:

- About Me.
- My Preferences.
- My Goals.
- My Businesses.
- My Projects.
- My Important Plans.
- My Approved Ongoing Tasks.

Only show categories containing relevant permitted information.

Separate saved memories from contextual information retrieved from conversation history or live account records.

Provide actual dates or sources where helpful.

## 10.2 Memory interaction controls

Users should be able to perform real actions:

**Remember this**
Save user-approved information.

**Edit**
Change inaccurate information.

**Forget**
Remove a selected saved memory.

**Why do you remember this?**
Explain the memory's stored origin and applicable permission.

**Show all memories**
Open the full memory management page.

**Stop remembering**
Disable creation of persistent memories.

**Clear my memories**
Initiate a clearly confirmed memory deletion workflow.

**Export memories**
Export the user's permitted saved memory records.

Make controls accessible through both conversation and the settings interface.

Avoid success messages unless the underlying change is confirmed.

## 10.3 Example interaction

User:
"Chale, what do you remember about me?"

Chale:
"Here is what you've chosen to let me remember. I have your preferred language, some information about your business and a few ongoing goals."

Chale then displays only actual saved details with controls for editing, deleting or reviewing them.

If no memories exist, explain that clearly.

## 10.4 Conversational memory modification

User:
"Chale, remember that I prefer simple English."

Chale must:

1. Recognize explicit memory-save intent.
2. Check whether the information is allowed to be stored.
3. Save it to the authenticated user's memory store.
4. Confirm only after persistence succeeds.
5. Respect the preference in relevant future chats.

User:
"Chale, forget that preference."

Chale must:

1. Find the correct memory.
2. Resolve ambiguity if multiple records match.
3. Delete or invalidate the applicable memory.
4. Clear associated active retrieval representations.
5. Prevent deleted memory from being silently recreated from old summaries.
6. Confirm the actual result.

Deleting a memory must not be misrepresented as deleting all past chat messages that originally contained it.

Clearly distinguish memory deletion, conversation deletion and retention of technical backups.
